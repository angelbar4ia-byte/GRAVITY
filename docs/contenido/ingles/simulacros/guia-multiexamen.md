# Guía multiexamen · preparación para TOEIC, Cambridge y TOEFL

> **Contexto:** nota general en `../CONTEXTO.md`. Estado de este documento: guía común para TOEIC, Cambridge y TOEFL; pendiente de aprobación.

> Versión 0.1 (14/nov/2026), para aprobación del dueño. Opción recomendada: **un examen principal por bimestre, con un simulacro de otro formato cada cuatro semanas**. El usuario elige cuál lleva: uno, dos o tres, alternados.

## 1. Principio

Los tres exámenes reciben **el mismo paquete de preparación**, con la misma calidad y la misma exigencia. Ninguno es secundario por defecto. El usuario decide cuál lleva; el sistema no cambia la rúbrica ni los umbrales según el examen.

## 3. Modos de elección

| Modo | Cómo funciona | Carga semanal |
|---|---|---|
| **Un examen** | Un examen principal durante todo el bimestre; sin cambios | Bajo |
| **Dos alternados** | Principal y secundario; el secundario cada cuatro semanas | Medio |
| **Tres alternados** | Los tres exámenes en rotación mensual; cada uno tiene su práctica por partes | Alto |

En cualquier modo: el umbral del bimestre es el mismo, las pruebas se califican con la misma rúbrica, y el progreso se registra por examen.

## 4. Secuencia didáctica (la misma para los tres)

1. **Diagnóstico:** una parte de cada habilidad antes de empezar el bloque, para ubicar el punto de partida.
2. **Práctica por partes:** una parte por sesión, con retroalimentación de cada error. Una parte se domina antes de pasar a la siguiente.
3. **Simulacro:** completo o por partes, según el material disponible, con el tiempo oficial.
4. **Revisión:** el error se clasifica (gramática, vocabulario, lectura, tiempo) y se programa su repaso espaciado.
5. **Repetición:** las partes con menos de 80 % vuelven en la semana siguiente.

Esta secuencia es igual para los tres exámenes. Lo que cambia es el contenido de cada parte.

## 5. Por qué esta es la mejor guía

- **Justa:** cada examen tiene la misma calidad y el mismo criterio de aprobación, así que el usuario elige por su objetivo, no por cuál está mejor preparado.
- **Didáctica:** la práctica por partes antes del simulacro reduce la carga de formato; el simulacro mide lo que ya se practicó.
- **Medible:** el progreso se compara dentro de cada examen y se resume en el mismo registro de bimestre.
- **Flexible:** un examen, dos o tres sin cambiar el sistema.
- **Honesta:** cada componente dice si está verificado o pendiente; no se presenta un material como oficial si no lo está.

## 6. Orden de construcción

1. **Cambridge B1 Preliminary:** banco por parte, práctica por partes y simulacro, en cuanto se confirme la Parte 3 de Reading y el desglose de Listening.
2. **TOEFL:** banco por sección (Reading, Listening, Writing, Speaking) con su formato 2026.
3. **TOEIC completo:** completar las partes faltantes de la sección 0 de `toeic-bimestre-2.md`.
4. **Cambridge B2 First:** cuando se confirmen los pesos que faltan.
