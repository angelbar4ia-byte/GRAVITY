# GRAVITY

App única del proyecto **Segundo Cerebro**: asistente tipo JARVIS que une Finanzas, Hábitos, Cuidados, Alimentación y la Casa.

| Dispositivo | Qué es |
|---|---|
| Laptop Windows | Sistema completo con la pantalla principal de GRAVITY |
| Teléfono Android | Lo mínimo para registrar y consultar el día |
| Tablet Android | Portátil, compartida en la casa, con cambio de usuario |
| Pulsera | Avisos cortos |

## Estado
Fase 0 (cimientos) en curso. Ver `docs/ROADMAP.md`.

## Contenido
| Ruta | Qué es |
