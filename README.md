# GRAVITY

Asistente virtual tipo JARVIS, en construcción.

## Objetivo

Construir un asistente personal capaz de entender instrucciones en lenguaje natural (voz y texto), ejecutar tareas y ayudar a organizar información y flujos de trabajo.
